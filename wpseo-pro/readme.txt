== Description ==

企业级 SEO 管理面板。实时 SEO 审计、单页编辑器、XML Sitemap、robots 管理与结构化数据。

特性：
- 后台 SEO 审计面板：标题、描述、图片、内部链接、关键词密度、标题结构一览。
- 单篇/单页 SEO 编辑器：实时调整标题、描述、焦点词，动态显示评分。
- 自动生成 XML Sitemap，支持索引、文章、页面、附件。
- robots.txt 可视化配置。
- 结构化数据（Schema）生成：Article、WebPage、Organization、Product、FAQPage 等。
- 暗色现代化后台，适合企业官网。

== Installation ==

1. 上传 `wpseo-pro` 目录到 `/wp-content/plugins/`
2. 在后台「插件」中激活 `WordPress SEO PRO`
3. 进入「SEO PRO > 设置」配置站点地图与基本选项
4. 进入「SEO PRO > SEO 审计」或「SEO PRO > SEO 编辑器」开始使用
